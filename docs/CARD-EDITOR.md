# 卡片编辑页与卡组织选择

- 新建、编辑、复制统一进入独立编辑页面，顶部返回 / 保存卡片。
- 基本信息、执行设置、APDU 规则、可折叠测试场景分区展示。
- APDU 规则进入子页面编辑；规则菜单提供编辑、上移、下移、移除。
- 返回时如有修改，提示继续编辑或放弃；规则保存只写入卡片草稿，点击保存卡片才持久化。
- 旋转屏幕、后台被系统回收后，在系统恢复该页面时恢复半成品草稿。草稿通过应用私有文件保存，Bundle 仅保存标识；主动退出并放弃会删除该草稿。
- 从详情进入编辑会暂停模拟；取消或保存后，保留进入编辑前的模拟开关意图。

卡组织固定选项为 Amex、Discover、JCB、Mastercard、UnionPay、Visa、其他。下拉末尾可添加组织，新增名称去除首尾空格、忽略大小写判重，独立保存在本地。导入文件中的未知名称保留，可直接选择。新增组织后取消编辑卡片，组织名称仍保留供以后使用。

首页 Tab 仅显示当前卡包实际使用的卡组织，固定组织顺序保留，其他组织追加在后。“全部”表示包内全部卡片。

首页工具栏主标题为当前卡包名称，点击进入管理页；副标题显示“NFC 卡模拟器 · v版本号”，版本读取已安装包信息。

验证：46 项单元测试通过；完整编辑 / 导航回归 12 项通过；新增卡组织、重复名称提示、选择恢复交互单独验证通过。Lint 无错误。模拟器验证不包含真实手机 NFC 射频能力。

v0.3.13：基本信息增加“所属卡包”，仅列出用户卡包。新建和复制默认进入当前用户包，当前包为内置时进入自建卡片；普通编辑保留原包。仅改变所属包也属于未保存修改，跨规则子页、页面重建均保留选择。保存时原子移动，目标相同卡片 ID 冲突会拒绝，原卡保留；复制会生成新 ID。

匹配设置界面：列表仅显示卡组织和规则数量。详情 APDU 规则区显示“内容匹配 / 顺序匹配”和未匹配回复，说明图标可查看区别。编辑页使用执行方式下拉；规则匹配方式统一显示完整、前缀、掩码的中文名称，按选择显示说明，仅掩码模式显示掩码字段。前缀及掩码模式提示固定回复限制。执行引擎、JSON 字段和已有卡片配置保持不变。
