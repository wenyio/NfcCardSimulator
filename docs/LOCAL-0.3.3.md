# 0.3.3 详情布局与顶部样式

- 首页分类 Tab 与卡片之间增加 12dp 间距；详情 Tab 下方使用相同间距。
- 状态栏与顶部工具栏统一为 #152538，状态栏使用浅色图标，启动主题也使用该配色。保留系统安全区域，工具栏内容不覆盖时间、电量或挖孔。
- 详情 / 调试 / 日志改用与首页一致的轻量 Tab；切换只更新视图，保持当前模拟会话和交易步骤。
- 卡名只保留工具栏标题；正文展示卡组织、来源、AID。说明超过三行默认折叠，可展开和收起。
- APDU 规则改为紧凑列表行，显示序号、名称和匹配方式；点击展开 T/C，掩码匹配同时显示 MASK。
- Tab、说明折叠、规则列表各自独立文件，界面核心交互附中文注释。
