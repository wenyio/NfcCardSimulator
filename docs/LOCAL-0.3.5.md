# 0.3.5 滑页与模拟状态整合

- 首页分类、详情/调试/日志支持内容区左右滑动；页面跟随拖动，松手后平滑切换，点击 Tab 也有过渡，下划线与页面联动。
- 详情各页缓存，保留输入、规则展开和滚动状态。切页不重选卡、不启动 NFC、不重置交易步骤。
- 独立 SwipePager 处理横向/纵向方向锁定；输入框、开关优先处理自身手势。
- 模拟控制卡固定在详情 Tab 上方，三个页面均可暂停模拟、查看状态。
- 状态圆点移到“卡片模拟”文字前：运行时绿色实心，停止时灰色空心，提供无障碍描述。
- 明确的启动问题显示为文字后的圈叹号，点击弹窗显示完整原因；成功启动或手动关闭后隐藏。移除顶部独立状态/错误文字行。
- 错误原因仍来自现有 NFC 路由检查，未修改平台注册限制。
