# 0.3 操作与导航

- 首页精简为卡片列表，顶部工具栏提供全部日志和设备设置图标。列表卡片整块可点击，更多菜单提供复制、编辑、导出、删除；内置卡使用“复制后编辑”。
- 打开卡片进入详情，自动尝试注册 AID 并启动；无需额外开启偏好。设备条件不足时留在详情显示原因，可打开设备设置。不会未经点击弹出系统默认支付选择。
- 详情内有详情/调试/日志三个页签。切换不重选卡、不重置已经执行的顺序会话。元数据、折叠规则和 JSON 查看位于详情。
- 返回列表（工具栏返回或系统返回）先停止模拟，再显示列表。列表没有开始模拟按钮。
- 进入设备设置或切到后台会停止；回到可见详情后恢复。进入编辑会暂停，取消或保存后恢复；保存新副本时打开该副本详情。详情手动暂停后，切页签不自动恢复；重新打开卡片则恢复默认自动模拟。
- 进程重启只恢复卡片数据，不恢复持久化模拟开关。旋转/重建详情重新建立模拟会话。
- 详情日志及导出按卡片 ID 筛选；顶部日志查看所有记录；本卡日志和全部日志均可清空，分别作用于当前卡或全部记录。0.2 历史记录没有卡片 ID，仍保留在全部日志中。

实现入口：nfc/DetailSimulationSession.kt 管理会话范围；ui/cards/CardDetailPage.kt、CardActions.kt、CardsPage.kt 分离展示和操作；ui/settings/DeviceSettingsPage.kt 封装系统设置入口。

真实手机仍需验证自动启动、默认支付返回、锁屏/后台、射频断开和终端交易；模拟器仅能验证规则和页面生命周期。
