# 1.0.0 清理与验证记录

- 版本 1.0.0，versionCode 19；只内置 6 张自编连通性演示卡。
- 移除第三方内置卡配置、对应清单、转换脚本及专属交付文档，原文件移至仓库外备份并校验 SHA-256。
- 默认卡包改为连通性演示；旧版本失效的卡包/卡片选择在升级后回退并更新偏好，不恢复模拟、不删除用户包和日志。
- 旧版 APK 移至仓库外，当前 artifacts 仅提供新版本产物。
- 本地仓库无远程、无其他工作树；按用户要求清空旧历史，以当前源码创建 1.0.0 单一初始提交。
- 52 项单元测试通过，Lint 无错误，14 项设备回归通过；APK 签名验证通过，包内 assets 仅 demo-cards.json。
- 设备测试覆盖演示卡只读、筛选、复制、升级回退、用户卡保留、卡包新建/移动/导入/切换/删除和 JSON 查看。
- 日志：work/build-1.0.0.log、work/1.0.0-device-tests-verified.log。

清理当前仓库不会移除仓库外备份、用户设备上的旧安装数据、其他人保存的旧副本。移除该数据也不构成对整个应用权利状态的法律结论。
